# Fixus Autohuolto

Single-file static demo website for Fixus Autohuolto, a car repair and parts
workshop in Kilo, Espoo (part of the nationwide Fixus network).

## How to open

Double-click `index.html` in a browser, or serve the folder statically:

```
npx serve .
```

Everything (CSS, JS) is inline in `index.html`. No build step, no dependencies.
